# Vrew 리뷰 데이터 분석

> **총 570건** | **평균 3.89점** | **긍정 56.7% / 중립 26.8% / 부정 16.5%** | 분석 기간: 2019.10 ~ 2026.03

Vrew(브루) 서비스의 App Store / Google Play 사용자 리뷰를 수집하고, 감성 분석을 통해 주요 불만 요소와 만족 포인트를 파악한 프로젝트입니다. 경쟁사(CapCut) 비교 분석, 시계열 변화 추적, 그리고 분석 방법론 개선(v2)까지 포함합니다.

## 분석 v2: 개선 분석

v1의 한계점을 전면 개선한 버전입니다.

### 개선 사항

| 한계점 | v1 | v2 |
|--------|------|------|
| 토큰화 | 정규식 (자막이/자막을 별도) | **kiwipiepy 형태소 분석** (자막으로 통합) |
| 감성 분류 | 이진 (긍정/부정) | **3클래스 (긍정/중립/부정)** |
| 감성 모델 | KoELECTRA만 (한국어 전용) | **KoELECTRA(한국어) + XLM-RoBERTa(영어/일본어)** |
| max_length | 128 토큰 | **256 토큰** |
| 분류 보정 | 없음 | **하이브리드 분류 (텍스트 + 별점 보조)** |
| 모델 검증 | 없음 | **Confusion Matrix + F1 + 언어별 정확도** |
| 정성 분석 | 키워드 빈도만 | **LDA 토픽 모델링** |

## 분석 파이프라인

### v1
1. **데이터 수집** — App Store RSS + Google Play Scraper (kr/us/jp)
2. **전처리** — 병합, 중복 제거, 텍스트 정제
3. **감성 분석** — KoELECTRA (2클래스, max_length=128)
4. **시각화** — 별점, 키워드, 워드클라우드, 시계열

### v2 (개선)
1. **언어 감지** — langdetect로 리뷰별 언어 식별
2. **형태소 분석** — kiwipiepy (한국어 명사/동사/형용사 원형 추출)
3. **감성 분석** — KoELECTRA 3클래스 (긍정>0.7, 부정<0.3, 중립), max_length=256
4. **모델 검증** — 별점 기준 Confusion Matrix, 언어별 정확도
5. **토픽 모델링** — LDA (긍정/부정 각 5개 토픽)
6. **시각화** — 14종 차트 (기존 + 검증 + 토픽)

## 실행 방법

```bash

pip install requests google-play-scraper pandas torch transformers wordcloud matplotlib tqdm kiwipiepy langdetect scikit-learn

# 1. Vrew 크롤링
python 분석/크롤링/테스트\ 코드/크롤링_2026.py

# 2. v1 분석
python 분석/크롤링/테스트\ 코드/통합_분석_2026.py

# 3. CapCut 크롤링 + v1 분석
python 분석/크롤링/테스트\ 코드/capcut_크롤링_분석.py

# 4. v2 개선 분석 (Vrew + CapCut + 비교, 전체)
python 분석/크롤링/테스트\ 코드/개선_통합_분석.py all
```
