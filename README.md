# Vrew 리뷰 데이터 분석

> **총 570건** | **평균 3.89점** | **긍정률 76.8%** | 분석 기간: 2019.10 ~ 2026.03

Vrew(브루) 서비스의 App Store / Google Play 사용자 리뷰를 수집하고, 감성 분석을 통해 주요 불만 요소와 만족 포인트를 파악한 프로젝트입니다. 경쟁사(CapCut) 비교 분석과 시계열 변화 추적까지 포함합니다.

## 분석 2. 기존 vs 신규 비교 (2025.11 → 2026.03)

4개월 간격으로 데이터를 재수집하여 변화 추이를 분석했습니다.

| 지표 | 기존 (2025.11) | 신규 (2026.03) | 변화 |
|------|---------------|---------------|------|
| 총 리뷰 수 | 532건 | 570건 | +38건 |
| 평균 별점 | 3.86점 | 3.89점 | +0.03 |
| 긍정률 | 77.1% | 76.8% | -0.3%p |
| 5점 비율 | 54.7% | 56.0% | +1.3%p |

### 결론: 유의미한 변화 없음

- 모든 주요 지표가 1~2%p 이내 변화
- 긍정적 해석: 사용자 인식이 안정적으로 유지
- 부정적 해석: 기존 핵심 불만(자막, AI, fps, 내보내기)이 **4개월간 해결되지 않고 지속**
- 주의 신호: 3점(중립) 리뷰의 긍정률 -2.5%p 하락

## 분석 3. 경쟁사 비교 — Vrew vs CapCut

| 지표 | Vrew | CapCut | 차이 |
|------|------|--------|------|
| 총 리뷰 수 | 570건 | 7,248건 | - |
| 평균 별점 | **3.89점** | 2.42점 | +1.47점 |
| 긍정률 | **76.8%** | 64.4% | +12.4%p |
| 1점 비율 | 16.0% | **51.0%** | CapCut 3.2배 |
| 5점 비율 | **56.0%** | 24.4% | Vrew 2.3배 |
| 한국 긍정률 | **67.3%** | 21.2% | +46.1%p |

### 핵심 발견: 불만 유형이 근본적으로 다름

| 구분 | Vrew | CapCut |
|------|------|--------|
| **불만 유형** | 기능 품질 (자막, AI, fps) | 과금 정책 (유료화) |
| **해결 가능성** | 기술 개선으로 해결 가능 | 비즈니스 모델 변경 필요 |
| **사용자 감정** | "좋은데 이것만 고쳐주세요" | "무료였는데 왜 돈 받아요" |

- CapCut 부정 키워드 TOP 30 중 **9개가 과금 관련** ("유료", "유료화", "pro", "돈을" 등)
- 한국 시장에서 CapCut 긍정률 21.2% → Vrew가 이탈 유저를 흡수할 기회

## 분석 파이프라인

1. **데이터 수집** — App Store RSS + Google Play Scraper (kr/us/jp)
2. **전처리** — 병합, 중복 제거, 텍스트 정제
3. **감성 분석** — KoELECTRA 모델 (jaehyeong/koelectra-base-v3-generalized-sentiment-analysis)
4. **시각화** — 별점 분포, 키워드 빈도, 워드클라우드, 시계열 추이, 플랫폼/국가별 비교
5. **비교 분석** — 시계열 비교 (기존 vs 신규), 경쟁사 비교 (Vrew vs CapCut)

## 실행 방법

```bash
# 패키지 설치
pip install requests google-play-scraper pandas torch transformers wordcloud matplotlib tqdm

# 1. Vrew 크롤링
python 분석/크롤링/테스트\ 코드/크롤링_2026.py

# 2. Vrew 분석 (전처리 + 감성분석 + 시각화)
python 분석/크롤링/테스트\ 코드/통합_분석_2026.py

# 3. CapCut 크롤링 + 분석 + 비교
python 분석/크롤링/테스트\ 코드/capcut_크롤링_분석.py
```
