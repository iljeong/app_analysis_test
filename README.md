# Vrew 리뷰 감성 분석 — 570건으로 "무엇부터 고칠지" 찾기

> 영상 편집 앱 **Vrew**의 앱스토어·플레이스토어 리뷰를 수집·정량화해, 별점만으로는 안 보이는 **불만의 구조와 개선 우선순위**를 데이터로 잡은 개인 프로젝트. 경쟁사(CapCut)와 비교하고, 다국어 감성 분석 정확도를 60% → 89.6%까지 끌어올린 과정을 담았습니다.
>
> `총 570건` · `분석 기간 2019.10~2026.03` · `한/영/일 3개국` · `모델 정확도 89.6%`

---

## 왜 만들었나 (문제)

앱 리뷰는 쌓이지만, **평균 별점 3.89점**이라는 숫자 하나로는 정작 팀이 알아야 할 걸 알 수 없습니다.

- 무엇 때문에 별점을 깎았는지 (기능? 안정성? 과금?)
- 그중 **뭘 먼저** 고쳐야 임팩트가 큰지
- 경쟁사 대비 우리 불만이 **구조적으로 다른지**

이걸 감으로 정하면 개선 우선순위가 틀립니다. 그래서 리뷰 텍스트를 감성·토픽으로 정량화하고, 경쟁사와 나란히 놓아 **"먼저 대응할 문제"를 데이터로 특정**하는 걸 목표로 잡았습니다.

## 그래서 무엇을 알아냈나 (결론)

**1. Vrew의 불만은 "분산형", CapCut은 "과금 집중형" — 대응 전략이 완전히 다름**

| 지표 (3클래스) | Vrew | CapCut |
|------|------|--------|
| 긍정률 | **66.1%** | 27.0% |
| 부정률 | 27.7% | **67.8%** |

토픽 모델링(LDA)으로 부정 리뷰를 분해하니, **CapCut 부정 5개 토픽이 전부 유료화/과금** 관련인 반면 Vrew는 일본어 처리·업데이트·내보내기 등 **기능 이슈로 분산**돼 있었습니다.
→ CapCut은 과금 정책 하나가 리스크, Vrew는 **여러 기능 이슈를 우선순위화**해야 하는 상황.

**2. Vrew의 핵심 강점은 자동 자막, 핵심 불만은 AI 인식 품질·앱 안정성·일본어 처리**

별점이 아니라 실제 텍스트에서 반복되는 신호로 확인. 개선 로드맵의 근거로 바로 쓸 수 있는 형태.

## 트러블슈팅 — 다국어 감성 정확도 60% → 89.6%

이 프로젝트에서 가장 오래 붙잡았던 문제입니다.

**증상.** v1(KoELECTRA 단일 모델)의 전체 정확도가 60%에 그쳤고, 특히 **일본어 리뷰 정확도가 41.3%**로 무너졌습니다. 절반 이상을 틀리니 일본어 불만 분석을 신뢰할 수 없었습니다.

**원인 진단.** KoELECTRA는 한국어 전용 모델인데 리뷰에는 한/영/일이 섞여 있었습니다. 여기에 정규식 토큰화가 "자막이 / 자막을"을 다른 단어로 세면서 키워드 신호까지 흐려졌습니다.

**해결 (v2).**

| 한계 (v1) | 개선 (v2) |
|--------|--------|
| 언어 구분 없이 한 모델 | `langdetect`로 언어 감지 후 **KoELECTRA(한국어) + XLM-RoBERTa(영어/일본어)** 분기 |
| 정규식 토큰화 | **kiwipiepy 형태소 분석** — 어미 제거·원형 통합 |
| 텍스트 예측만 | **하이브리드 분류** — 텍스트 예측 + 별점 보조 신호 결합 |
| 이진(긍/부) | **3클래스(긍/중/부)** + threshold grid search |
| 검증 없음 | **Confusion Matrix + F1 + 언어별 정확도**로 계측 |

**결과.**

| 단계 | 전체 | 한국어 | 영어 | 일본어 |
|------|------|--------|------|--------|
| v1 (KoELECTRA only) | 60.0% | 70.4% | 64.8% | 41.3% |
| v2 텍스트 전용 | 74.4% | 76.2% | 74.1% | 71.5% |
| **v2 하이브리드** | **89.6%** | **92.5%** | **90.7%** | **82.7%** |

무너졌던 일본어 정확도를 **41.3% → 82.7%**로 끌어올려, 다국어 리뷰 분석을 신뢰할 수 있는 수준으로 만들었습니다.

## 경쟁사 비교 상세 — Vrew vs CapCut

| 지표 | Vrew | CapCut |
|------|------|--------|
| 긍정률 (3클래스) | **66.1%** | 27.0% |
| 중립률 | 6.1% | 5.1% |
| 부정률 | 27.7% | **67.8%** |
| 모델 정확도 (하이브리드) | 89.6% | 90.2% |

### 부정 토픽 구조 (LDA)

| Vrew 부정 토픽 (5개) | CapCut 부정 토픽 (5개) |
|---------------------|----------------------|
| 1. 일본어 단어 오류/개선 요청 | 1. **Pro 구독 불만 (영어)** |
| 2. 업데이트/안드로이드 대응 | 2. **구독/결제 불만 (영어)** |
| 3. 일본어 번역/자막 이슈 | 3. **결제/환불 이슈 (한국어)** |
| 4. PC/UI 기능 이슈 | 4. **유료화 불만 (일본어)** |
| 5. 내보내기/자막 이슈 | 5. **유료화 불만 (한국어)** |

> CapCut은 5개 토픽 전부 과금 관련, Vrew는 기능 이슈로 분산 — 불만의 성격 자체가 다름.

## 분석 파이프라인

**v1 (기본)** — App Store RSS + Google Play Scraper 수집(kr/us/jp) → 병합·중복 제거 → KoELECTRA 2클래스 감성 → 시각화

**v2 (개선)**
1. **언어 감지** — langdetect로 리뷰별 언어 식별
2. **형태소 분석** — kiwipiepy (명사/동사/형용사 원형 추출)
3. **감성 분석** — KoELECTRA(한국어) + XLM-RoBERTa(영어/일본어), threshold grid search, max_length=256
4. **하이브리드 분류** — 텍스트 예측 + 별점 보조 신호 결합
5. **모델 검증** — Confusion Matrix, 언어별 정확도
6. **토픽 모델링** — LDA (긍정/부정 각 5개 토픽)
7. **시각화** — 14종 차트
